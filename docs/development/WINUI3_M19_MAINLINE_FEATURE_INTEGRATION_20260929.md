## New separately compiled preview-only features

- `experiments/phase6_winui_shell/m19_workspace.h/.cpp` provides a **read-only/CREATE_NEW-only** MFC UXH-07 `.fxworkspace` UTF-16 schema-1 compatible subset. It handles exactly one/two horizontal panes, up to32 tabs per pane, selected tab per pane and local filesystem/native `::` parsing paths. Validates extension, 1MiB maximum, no reparse files, BOM and UTF-16, unique keys, required first tabs, supported pane count and available local directories before touching any WinUI view. Excludes MFC full option keys, complete tab history and 33-64-tab/more-than-two-pane layouts; **subset** is intentional. Saving never overwrites an existing file or writes any legacy MFC profile.
- `m19_features.cpp`, `MainWindow.xaml/.h/.cpp` add native XAML collapsed-by-default **Workspaces** panel and **Search** panel. Background workspace validation/creation and only the **exact current WinUI executable** spawn a separate named-workspace window using `--m19-workspace`; route-tokens plus the existing two independent native Shell helper processes reconstruct selected and inactive tabs. The originating WinUI or MFC window remains unmodified. A new user navigation cancels stale pending tab-restoration tasks.
- `m19_search.h/.cpp` implements a **bounded read-only filename-contains search**, NOT full old MFC `SearchFile` regex/content/exclusion search. Separate native filesystem thread; max2500 walked entries, max depth5, max100 shown results, no traversal into reparse subfolders, cancellable with route/epoch stale protection. Recent scope persistence is **EXPLICIT opt-in only**, at most8 unique filesystem directory paths (no search text/exclusions), private UTF-16 `%LOCALAPPDATA%\flyExplorer.WinUI3Preview\recent-scopes-v1.txt`, never `%APPDATA%\fxfile\conf` or MFC `DlgState`. Full scope is visible in XAML; saved entries are selectable and clear persists across actual process restart.
- MFC UI-02 native ModernUI remains in the merged native source; new WinUI uses native XAML ListView/TabView built-in theme/scroll behavior, not a duplicate unsafe cross-framework renderer.
