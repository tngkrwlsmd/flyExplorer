# flyExplorer 향후 개발 목표 및 미완료 검증 항목

기준: 2026-10-19, `flyExplorer/main` `7ac35a06891496b831084d5d291d23b31629a3c4`.
이 문서는 **향후 작업을 재개할 때 확인할 목표 목록**이며, 구현·원격 실행·PR·배포의
자동 승인이나 이 문서 작성 시점의 신규 테스트 PASS를 뜻하지 않는다.
현재 상태 및 수용의 기준은 최신 소스, `CURRENT_STATUS.md`, `UI_UX_AUDIT.md`,
정확한 SHA/환경의 중앙 Windows 증거다. 작업 시작 시 반드시 다시 대조한다.

## 완료·보존할 기준선

- 제품은 `app/winui`의 C++/WinRT WinUI 3 파일 관리자다. Window Tab 아래에
  좌우 독립 패널과 패널별 폴더 탭(PaneTab)을 두는 구조를 유지한다.
- V8-A~E 컨트롤러 분리와 후속 세부 컨트롤러 경계는 구현되어 있다.
- F01 표시 옵션, F02 상세 정보, F03 제한된 미리보기, F04 로컬 폴더 트리,
  F05 네 가지 그룹화, F06 주소·탭 제스처는 **각 기록된 범위에서** 구현·검증되었다.
  F04의 현재 로컬 고정 드라이브 범위와 F03의 제한된 안전한 미리보기는 의도된
  제약이며, Windows Explorer와 기능이 다르다는 이유만으로 결함으로 재분류하지 않는다.
- 2026-10-19 R1 정렬 메뉴의 8개 현재 모드 체크 표시가 `7ac35a06`의
  `main`에 반영됐다. 같은 소스 변경의 제한적 96 DPI Light/Dark 실제 GUI/픽셀
  수용 기록은 `CURRENT_STATUS.md` 및 `UI_UX_AUDIT.md`에 있다.
  중앙 `desktop-a` [39188826255](https://github.com/tngkrwlsmd/personal-control-plane/actions/runs/39188826255)는
  정확한 `7ac35a06`에 대한 **source** PASS일 뿐, 새로운 full GUI/Debug/
  고배율/배포 수용을 뜻하지 않는다. R1을 미완료 기능으로 다시 열지 않는다.
- 기존 96 DPI GUI·테마, 제한된 필터 고대비, 실제 두벌식 필터 저장 PASS는 해당
  소스·조건에 한해 보존한다. 과거 FAILED/환경 차단 기록도 덮어쓰지 않는다.

## 향후 작업자의 절차와 종료 조건

1. 최신 `main` HEAD, 최근 커밋, 중앙 CI **실제 scope**, 관련 코드,
   `CURRENT_STATUS.md`·`UI_UX_AUDIT.md`를 다시 읽는다. 과거 '미구현'
   문구를 최신 수용보다 우선하지 않는다.
2. 해당 목표에 대해 **현재 기능, 확인된 차이, 미검증 조건, 의도적인 제약**을
   먼저 분류한다. 화면·키보드·OS 제공자 문제는 입력→이벤트→모델→표시 경계에서
   가장 작은 테스트로 확인한다.
3. 소스/빌드/GUI/실제 픽셀/High Contrast/음성/DPI/배포의 PASS는 서로 다르다.
   UI 픽셀을 변경한 경우 실제 앱의 같은 조건 BEFORE/AFTER 캡처·직접 검토가
   필수다. 원본 이미지를 보지 않고 시각 PASS로 보고하지 않는다.
4. 작업 종료 시 목표 ID, 결정 및 변경 파일, 검증한 SHA/환경/범위/실제 결과,
   남은 미검증, 다음 조건을 문서에 갱신한다. 한 목표가 수용되면 완료 기준선으로
   옮기고 새 기능 작업을 자동 시작하지 않는다.
5. `AGENTS.md`와 `AGENT_EFFICIENCY.md`의 최소 변경/검증 비용/데이터 보호,
   현재 중앙 Windows 운영 경계 및 사용자별 승인 규칙을 따른다. PR은
   별도 지시 없이 만들지 않고, 사용자 소유 파일·전역 설정을 임의 변경하지 않는다.
