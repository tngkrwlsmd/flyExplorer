# flyExplorer 향후 개발 목표 및 미완료 검증 항목

2026-10-30 사용자 추가 지시: 야간·06:00 종료 제한을 해제하고, 별도 중단
지시가 있을 때까지 실제 개발을 이어간다. [야간 PR #70](NIGHT_DEVELOPMENT_20261029.md)의
기존 구현을 보존하며 [계속 개발 기록](CONTINUOUS_DEVELOPMENT_20261030.md)을 따른다.
문서의 과거 미채택 표기가 이번 명시적 기능 개발을 차단하지 않는다.
Windows VM 금지와 Windows 수용 전 main 병합 금지는 유지한다.
공식 문서에 따른 기능 비교와 실제 Explorer/앱 실행 비교를 구분한다.

현행 정리: 2026-10-29. 저장소 대조 기준은
`main@d78cdaee42fe751558305d0f31191535342323d4`와 이번 탐색 버튼 갱신 blob이다.
최초 목록(2026-10-19)과 아래 날짜별 계획은 이력으로 보존한다.
이 문서는 작업 선정 지침이며, 새 기능 채택·외부 전송·제품 정책 변경의 승인이 아니다.
실행 시에는 최신 main, [현재 상태](CURRENT_STATUS.md),
[UI 점검](UI_UX_AUDIT.md)과 정확한 소스·실행 파일별 증거를 다시 대조한다.

## 현재 결론

최초 우선 과제였던 Home 축소 문제, 한 로컬 대량 폴더의 병목 개선,
Light 캡션 대비, PX17의 안전한 새 항목 메뉴는 기록된 범위에서 완료됐다.
후속 검색 패널 축소, 긴 미리보기 문자 경계, 축소 후 포커스 버튼 표시도
완료됐다. 이후 검색 가로 스크롤, L03 점파일 유형 문구, M24 .txt 아이콘 준비 화면도
각 기록된 범위에서 수용됐다. 이들을 미완료로 남겨 변형 검사를 늘리지 않는다.
전체 제품·전체 PX15·모든 성능 환경의 수용을 뜻하지도 않는다.

이번 검증 제품은 `d78cdaee` + `MainWindow.xaml.cpp@b2cd9c72…`다. `7e28366c`의 충돌/탐색 차단·정렬 전 필터와
후속 충돌 취소 복구를 포함한다. 실제 F6 모달 우회도 [집중 수정·수용](EP05_MODAL_SHORTCUT_ACCEPTANCE_20261029.md)했다. Release와 충돌 취소 한정 GUI/픽셀은 통과했다.
필터 정렬의 native/실제 앱 순서와 선정한 빈 결과 화면도 확인했다. 실제 앱
속도 개선은 확인하지 못했다. 탐색 시작의 갱신 누락을 수정해 [한정 pending 탐색 GUI/화면](EP01_NAVIGATION_CHROME_ACCEPTANCE_20261029.md)은 수용했다.
[충돌 복구](EP05_CANCEL_RECOVERY_20261029.md),
[필터 실측](PX13_FILTER_SORT_ZERO_RESULTS_20261029.md),
[탐색 수용 경계](EP01_NAVIGATION_BOUNDARY_20261029.md)를 구분한다.

남은 항목은 **검증 공백**, **선택적 확장 결정**, **미채택 기능 후보**,
**새 증상이 있을 때만 재개할 작업**으로 구분한다. 다음 순서는 권고이며,
새로 재현된 결함은 사용자 영향에 따라 우선할 수 있다.

### 다음 작업을 시작하는 방법

1. 최신 main·최근 커밋·열린 PR/이슈·중앙 실행/Windows 슬롯을 읽고,
   요청한 단위가 이미 완료됐다면 그 증거를 재사용한다.
2. 다음 단위의 사용자 동작, 현재 문제 또는 검증 공백, 관련 파일,
   원래 설정/소유 데이터 보호와 최소 완료 조건을 짧게 정한다.
3. 이번 1~5의 통과한 범위는 재사용하고 남은 경계를 먼저 대조한다. 새로운
   PX15 단위는 별도 가치/증거가 있을 때 한 건만 선정한다. 실제 Explorer와
   대조하지 않았다면 Explorer 대조 미검증으로, UIA만 확인했다면 픽셀
   미검증으로 기록한다. 단순히 PARTIAL 표기를 없애기 위한 전체 GUI·
   조합별 화면 검사·동일 현상 반복은 하지 않는다.
4. 결함이 확인되면 기존 Controller와 Windows API/Explorer 위임을 우선해
   필요한 코드만 수정한다. 변경 기능과 실제 의존성만 검증하고, 호환 가능한
   중간 산출물을 재사용한다. 기능 GUI와 실제 화면 검토를 구분한다.
5. 소스 SHA/후보 blob·실행 파일·환경·실제 결과·미검증 범위를 기록하고,
   테스트 소유 파일/프로필을 정리한다. 허용된 GitHub 반영과 동기화 후
   해당 단위를 종료하고, 다음 미완료 항목으로 이동한다.
6. 결정 대기/미채택 항목은 일반적인 “이어서 진행”으로 자동 채택하지 않는다.
   결정이 필요한 변경은 구체적인 선택과 영향을 제시하고 현재 계약을 유지한다.
   실행할 근거 있는 다음 작업이 없으면 그 사실을 보고한다.

### 유지할 경계와 재개하지 않을 작업

- 듀얼 패널과 WindowTab → PaneTab, 현재 혼합 상태 소유 계약을 유지한다.
  정렬은 PaneTab별 v4 저장, 보기/표시 옵션/열 너비는 WindowTab의 좌·우
  패널별, 그룹화는 임시 캐시다. F14의 폴더 보기 기억은 세션 내 기능이다.
- 이전 캡처의 상단 도움말 잔류는 [실제 입력 진단](F03_PREVIEW_PANE.md)에서
  재현되지 않았다. 원인을 자동화로 단정하거나 해결 완료로 기록하지 않는다.
  새로운 동일 조건 근거 없이 이 관찰이나 완료된 G01을 반복 시험하지 않는다.
- G03 실제 125/150/200% DPI, G04 고대비/Narrator, G05 실제 USB/SMB/UNC/
  매핑 드라이브는 **USER-EXCLUDED**, G07 실제 한국어 IME는 **사용자 중단**이다.
- 공개 배포·스토어·공개 릴리스·서명은 현재 목표가 아니다. 원래 사용자 파일,
  설정, 전역 클립보드와 실제 휴지통을 임의로 변경하지 않는다.
- Work 클라우드와 승인된 `personal-control-plane`의 `windows-vm` 경로를 사용한다.
  개인 PC·로컬 데스크톱·RDC·`chatgpt-codex-connector`로 우회하지 않는다.
- 문서만 바꾸는 후속 작업은 제품 빌드·GUI를 실행하지 않는다. 이번 실제 검증은
  위의 정확한 run/source/runtime 범위로만 기록한다.
