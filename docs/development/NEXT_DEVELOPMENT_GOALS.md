멤버 이름으로 공개한다. 파일·ZIP 크기/경로/헤더/파일 존재 여부를
엄격히 검사한다. 손상·충돌은 기존 항목 불변 및 예약 임시 출력
정리로 처리하도록 작성했다. Deflate·하위 폴더·복수 엔트리/ZIP64
등은 아직 거부한다. **빌드·실행·GUI·시각 검증은 NOT TESTED**.

## 2026-10-21 EP10/F08 ZIP Store 생성 — 단일 파일 코드 반영, 미검증

선택한 일반 로컬 고정 드라이브 파일 한 개(최대 8 MiB)를 동일
폴더의 <원본파일명>.zip 파일에 UTF-8 이름/CRC32가 있는 ZIP
Store(압축 없음) 방식으로 묶는다. 임시 파일에 완전히 기록한 후
원자적 rename(덮어쓰기 없음)하며 원본은 건드리지 않는다.
