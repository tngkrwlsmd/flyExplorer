# R12a — 보기 메뉴에서 세부 정보 창 열기 (2026-10-31)

Windows 11 탐색기와 비교한 R12 중 실제 GUI에서 이미 성공 근거가 있는 부분만 독립적으로 구현한다. 상단 **보기** 메뉴와 파일 목록 **빈 배경 > 보기** 하위 메뉴에서 현재 창의 **세부 정보 창**을 표시하거나 숨기고, 기존 패널 표시 상태를 체크로 보여준다. 기존 파일 이름·크기·위치 등의 세부 정보 패널을 재사용하며 새 미리보기 엔진을 만들지 않는다.

- **소스 범위:** `FileToolbar.xaml/.h/.cpp`, `MainWindow.xaml.cpp`, `m22_transfers.cpp`, 새 소스/GUI 계약, 소스 검사 등록. 기존 보기 모드 8종·패널/탭/세션 v4·파일 작업·OS 클립보드·휴지통 로직은 변경하지 않는다.
- **보호 경계:** 파일 작업이 바쁘거나 충돌 확인을 기다리는 경우 새 메뉴 명령을 차단한다. 빈 배경 하위 메뉴는 기존 활성 WindowTab·PaneTab·route·파일시스템 경로 소유권 검사를 거친다.
- **읽기 경계:** 세부 정보 창 열기로 텍스트를 자동 읽지 않는다. 파일 본문 미리보기는 기존 `텍스트 미리보기 켜기` 버튼의 명시적 클릭이 계속 필요하다.
- **분리한 이슈:** 기존 R12 전체 후보의 **텍스트 미리보기 버튼으로 이동** 메뉴 항목은 [포인터 재현 #41195201589](https://github.com/tngkrwlsmd/personal-control-plane/actions/runs/41195201589)에서 실제 마우스 클릭이 전달되지 않아 이 한정 구현에서 **제외**했다. UIA Invoke에서는 작동했지만 이를 마우스 검증 성공으로 바꾸어 기록하지 않는다. 기존 Alt+P와 패널 안의 명시적 버튼을 유지한다.

**현재 상태:** 소스 및 테스트 후보를 만들었으며, Windows 소스 검사·Release·소유 GUI 실제 마우스 열기/닫기 및 원본 보존 확인 전까지 미수용이다. R11이 반영된 제품 main `c260e1c18f492d940b9338c85c88ea71ac252e64`을 기반으로 독립 구현한다.
