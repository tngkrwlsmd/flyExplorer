현재 개발 및 검증 환경

2026-09-24 기준 기본 개발 및 검증 대상은 Windows 10/11 데스크톱이며, 기본 빌드/CI 구성은 Release-x64-Unicode | x64입니다.

x86 Unicode/Multibyte 구성은 호환성 및 배포 자산으로 남아 있으나 현재 기본 검증 범위에 포함되지 않습니다. 과거 Windows 버전 지원이나 구형 하드웨어 사양은 최신 개발 버전에서 검증되지 않았습니다.

현 개발 버전의 최소 CPU, 메모리, 화면, 디스크 요구사항은 별도 측정이 필요합니다. 개발 도구는 Visual Studio 2026, MSVC v145, MFC, Windows 10/11 SDK, Python 3.9 이상이며 일반 사용자가 프로그램을 실행할 때 설치할 필요는 없습니다.

이 페이지는 도움말 원본입니다. 배포 중인 기존 fxfile.chm은 Windows 도움말을 별도 재생성하기 전까지 과거 내용을 표시할 수 있습니다. 최신 개발 환경과 검증 상태는 저장소 README와 .agent-policy/PROJECT.md를 참조하십시오.
