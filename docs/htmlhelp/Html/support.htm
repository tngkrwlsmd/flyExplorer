fxfile 개발 버전 지원 및 문의 안내

현재 개발 버전 2.0.4-dev의 기능 및 검증 범위는 현재 사용 안내를 참고하십시오. 저장소 README에는 개발 관련 설명과 과거 프로젝트 연락처가 기록되어 있지만, 이전 웹사이트나 이메일 주소의 현재 운영 상태는 별도로 검증되지 않았습니다. 기존 연락처를 공식적인 실시간 지원 보장으로 해석하지 마십시오.

현재 프로그램에서 재현 가능한 문제가 있다면 사용한 빌드 버전과 Windows 버전, 수행한 동작, 예상 결과, 실제 결과 및 필요한 경우 개인정보를 제거한 화면을 함께 정리하는 것이 도움이 됩니다. 문제 보고 경로는 이용 가능한 프로젝트 저장소 또는 현재 개발팀이 지정한 경로를 확인하십시오.

기존 도움말의 2010년대 웹 게시판·이메일 기반 지원 약속은 현재 운영을 확인할 수 없어 최신 안내에서 제외했습니다. 과거 내용은 Git 버전 이력으로 보존됩니다.
