fxfile 2.0.4-dev 현재 사용 안내

문서 기준: 현재 flyExplorer/fxfile 소스와 빌드 설정을 확인하여 작성한 기본 안내입니다. 개발 버전이므로 화면 구성과 메뉴 문구는 빌드·언어·사용자 설정에 따라 달라질 수 있습니다. 최종 Windows 화면 및 접근성 동작은 아직 별도 검증이 필요합니다.

개발 대상과 기본 구성

현재 기본 개발 및 검증 대상은 Windows 10/11 데스크톱이며 기본 빌드 구성은 Release-x64-Unicode | x64입니다. x86 Unicode 및 Multibyte 프로젝트와 구형 Windows 호환성 자산은 남아 있지만 현재의 기본 검증 범위에 포함되지 않습니다. 과거 안내의 Windows 98/XP 등 최소 지원 환경을 현재 버전의 보증으로 해석하지 마십시오.

파일 및 폴더 탐색

프로그램 소스에는 주소 표시줄, 폴더 트리, 파일 목록, 여러 창으로 나누어 보는 기능과 탭이 존재합니다. 폴더 이동 후 주소 표시줄과 현재 활성 파일 목록의 경로를 확인하십시오. 다른 창이나 탭으로 이동한 뒤 파일을 복사·이동·삭제하기 전에는 현재 활성 창과 선택 항목을 다시 확인하는 것이 안전합니다.

기본 명령 모음에는 뒤로, 앞으로, 상위 폴더, 검색, 잘라내기, 복사, 붙여넣기, 이름 변경, 삭제, 새 폴더 만들기 등 파일 관리자 명령이 연결되어 있습니다. 명령 아이콘은 현재 Fluent 기반 자산과 이전 비트맵 호환 자산을 함께 사용하므로 이전 도움말의 도구 모음 그림과 다를 수 있습니다.

외형과 탭 설정

현재 환경 설정의 외형 관련 소스는 시스템 / 라이트 / 다크 테마 모드 선택을 제공하며 탭의 동작·표시와 관련한 설정을 별도로 보유합니다. 테마 변경 및 Windows 고대비 모드의 표시 결과는 실제 Windows 환경의 수동 검증이 필요한 항목입니다. Windows 고대비 사용 시에는 운영체제 접근성 설정을 우선하십시오.

단축키와 이전 자료

전역 단축키 설정 화면과 단축키 관련 소스가 유지됩니다. 실제 적용된 단축키는 프로그램 설정과 사용자 변경 사항을 확인하십시오. 과거 단축키 표는 참고 자료일 뿐 현재 설치 상태에서 모든 조합이 유효하다는 보증이 아닙니다.

다음 문서들은 과거 릴리스의 상세 참고 자료로 보존합니다: 이전 버전 화면 설명, 메뉴 안내, 환경 설정 설명, 기능별 참고, 과거 릴리스 이력. 과거 스크린샷·설정 위치·메뉴 구성은 현재 개발 버전과 다를 수 있습니다.

자동 업데이트 기능

현재 소스와 새 설치/포터블 패키지에서는 자동 업데이트 검사 및 버전 다운로드 기능을 제공하지 않습니다. 이전 설치본을 사용했던 경우 Windows 시작 프로그램에 남은 이전 업데이트 도우미는 별도로 확인하십시오. 현재 기능이 검증되지 않은 과거 도움말의 자동 업데이트 설명은 적용되지 않습니다.
